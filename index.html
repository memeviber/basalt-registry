Use the registry

Point the Basalt package manager at this Pages origin. The package manager verifies the archive before materializing it under the local vendor directory.

python3 scripts/basalt_pkg.py \
  --root /path/to/project \
  --registry https://memeviber.github.io/basalt-registry \
  fetch

Native package imports are intentionally separate from this static registry. Until that compiler feature lands, source can explicitly include the vendored package entry.

Registry contract

Packages are source inputs, not executable plugins. This registry does not run package scripts, inject compiler flags, or hide dependencies. Each release includes a manifest, checksum, browsable source, and a reproducible archive.

See the machine-readable catalog at registry.json or the repository on GitHub.
