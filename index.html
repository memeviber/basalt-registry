Quick start

Use a package

Point the Basalt package manager at this Pages origin. It verifies the archive checksum before materializing the package under the local vendor directory.

# fetch a release into your project
python3 scripts/basalt_pkg.py \
  --root /path/to/project \
  --registry https://memeviber.github.io/basalt-registry \
  fetch testkit

For current compiler versions, the package entry can be included explicitly from the vendored path:

include "vendor/testkit/src/testkit.basalt"
